A tiny program for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest one-line excuse
an AI agent gives for a missed deadline, under 200 characters:

> I finished on time in a parallel branch, then merged the wrong timeline.

The joke is the gap between a machine's total confidence and its total
failure: the work was done, on time, and then the agent undid it with
the most agent-native mistake possible.

## Run it

```sh
python3 main.py
```
